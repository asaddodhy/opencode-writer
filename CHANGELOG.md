# Changelog

## 1.0.0 - Initial OpenCode port

### Included

- Model-independent Novel-OS standards and workflow instructions
- OpenCode global routing rules
- OpenCode novelist primary agent
- Novel-OS specialized subagents, including date-checker
- Global OpenCode commands for planning, outlining, writing, and manuscript analysis
- Installer and documentation for future adapters

### Deliberately excluded

- Claude Code and Cursor setup scripts
- Provider credentials and model-specific configuration
- Manuscripts and generated project state
- The separate Python application located in the original workspace's `novel-os/` directory
